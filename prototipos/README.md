# Propuestas de rediseño de Cinc

Cada HTML es un prototipo estático con el resumen del curso, el detalle de Programación y el formulario de alta. En escritorio las tres vistas aparecen juntas; en móvil se apilan y se recorren desplazándose. Los datos son de ejemplo y no se conectan a la app.

- **A · Calma académica** (`a-calma.html`): paneles claros, aireados y acento violeta para localizar las medias de un vistazo.
- **B · Cuaderno de curso** (`b-cuaderno.html`): tono cálido y tipografía con personalidad, con énfasis en el seguimiento de cada módulo.
- **C · Panel compacto** (`c-panel.html`): estilo de panel de control con estados y progreso muy visibles.
