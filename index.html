Módulos

Nueva nota

Si aún no tienes la nota, déjala vacía y saldrá como pendiente. El peso es 1 salvo que la actividad cuente más.

Nuevo módulo

Sin reparto, la media del módulo es la media de todas sus notas.

Copia de seguridad

Tus notas se guardan solo en este dispositivo. Descarga una copia para no perderlas o para pasarlas a otro dispositivo.

Última copia: nunca
